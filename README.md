# 롤 밴픽 추천기 (KR 솔로랭크)

롤 클라이언트 픽창을 자동으로 읽어서, 내 차례에 예상 승률이 가장 높은 챔피언을 추천해요.

## 피방에서 쓰기
1. 이 저장소의 **Releases → 최신 버전**에서 `LolDraft.exe`를 받아요.
2. 롤을 켜고 `LolDraft.exe`를 더블클릭해요. 설치할 건 없어요.
3. 픽창에 들어가면 추천이 저절로 바뀌어요. 클라이언트가 꺼져 있으면 칸에 직접 입력해서 쓸 수 있어요.

exe가 막히면 `LolDraft.zip`을 받아 압축을 풀고 실행해 보세요.

## 참고
- 롤 클라이언트가 내 컴퓨터 안에서 여는 통로(LCU API)를 **읽기만** 해요. 클라이언트를 조작하지 않고, 다른 플레이어 정보도 보지 않아요.
- 조합만 본 확률이라 1~2%p 차이면 손에 익은 챔피언이 더 나아요.
- `model.json`을 새로 학습한 걸로 바꿔 올리면 exe가 자동으로 다시 만들어져요.
